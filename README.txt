NEW GRANTHI SINGH FEDERATION — MULTI-PAGE WEBSITE STARTER

Pages:
- index.html — Home
- about.html — About Us
- membership.html — Membership interest form (demo only)
- donations.html — Donation information / pledge form (demo only)
- activities.html — Activities, projects and internships
- events.html — Events
- team.html — Management team
- news.html — News and updates
- contact.html — Contact and enquiry form (demo only)
- admin-demo.html — public planning page for future admin features (NOT a secure admin panel)

Publish with GitHub Pages:
1. Extract this ZIP on your phone/computer.
2. Create a PUBLIC GitHub repository.
3. Upload all files and folders, keeping the assets folder and its style.css.
4. In repository Settings > Pages, choose Deploy from a branch, branch main, folder /(root), then Save.
5. Wait for the Pages URL to appear.

Important:
This is a static front-end starter. Forms do not send or save information, donations are not processed, and there is no secure admin login, database, QR verification, receipts, member ID generation or payment gateway. These require backend/authentication/payment integration. Replace sample phone/email/address and sample text before publishing.
